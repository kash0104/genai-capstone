# Interview Bank

Answer in your own words, out loud first, then write. If you can't explain it simply, you don't know it yet.

## Week 1 — How LLMs see text

1. What is a token, and why do LLMs work on tokens instead of characters or whole words?
2. Why can an LLM get the number of r's in "strawberry" wrong?
3. What does temperature do mathematically? When would you set it to 0?
4. A user's 5-word message is billed as ~30 input tokens. Why?
5. What is a context window, and what happens when a prompt exceeds it?
